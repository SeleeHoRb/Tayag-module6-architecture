## Project Overview
The Student Task Management System is a web-based application designed to help students organize, manage, and monitor their academic tasks in one centralized platform. It enables students to keep track of assignments, projects, quizzes, and other school-related activities by providing an organized list of tasks with corresponding deadlines and progress status. The system also allows teachers to create and assign tasks, monitor student progress, and manage submissions efficiently.
## Problem Statement
Many students struggle to organize assignments, projects, quizzes, and deadlines. They often forget submission dates, leading to late submissions and poor time management. Teachers also find it difficult to monitor students' task completion and progress efficiently.

The proposed Student Task Management System provides a centralized platform where students can manage academic tasks while teachers can assign and monitor them.
## Target Users
The Target Users of this System are the students of Concepcion Holy Cross College and The Admins/Resgister of CHCC
## Main Features
1. Task Management
Create, edit, and delete tasks
Set due dates
Categorize tasks by subject
2. Task Tracking
Mark tasks as Pending, In Progress, or Completed
View task completion progress
Filter tasks by subject or status
3. Notifications and Reminders
Display upcoming deadlines
Send reminders before due dates
Highlight overdue tasks
